# CI plan: Excalidraw to Notion

Every push to `main` that touches a diagram renders all `.excalidraw` files to PNG and
publishes them to a **Diagrams library page** in Notion. Each diagram lives there in a
synced block. You place a diagram on any other page by pasting a synced copy of that
block, and every copy follows each update. There are no block IDs to copy into the
repo.

## Overview

```
push to main
  -> GitHub Action
     1. npm ci + install headless Chromium
     2. scripts/export.mjs            renders every .excalidraw file to build/*.png
     3. scripts/upload-to-notion.mjs  uploads every PNG and syncs the library page
```

- **Rendering** uses the official `@excalidraw/utils` package inside headless Chromium
  through Playwright. This matched the Excalidraw editor exactly in an earlier test,
  including fonts.
- **Uploading** uses the Notion File Upload API.
- **The library page** has, for each diagram, a small heading with the diagram's repo
  path (for example `Test2/test2.excalidraw`), followed by a synced block that contains
  the image. On each run the script reads the page and then:
  - updates the image inside the synced block for diagrams that are already there.
    Every synced copy elsewhere in Notion shows the new picture.
  - appends a new heading and synced block for diagrams that aren't there yet.
  - logs a note for entries whose diagram was removed from the repo. It never deletes
    anything in Notion.
- **Only the library page is read**, so a run stays fast however many pages use the
  diagrams.

## 1. Notion setup (test workspace)

1. In your personal workspace, create an internal integration at
   https://www.notion.so/profile/integrations.
2. Give it these capabilities:
   - **Read content:** on
   - **Update content:** on
   - **Insert content:** on. It's needed to add new diagrams to the library page.
   - **Comments:** off
   - **User information:** "No user information"
3. Copy the integration's secret token.
4. Create an empty page named **Diagrams**. Open its `•••` menu, choose
   **Connections**, and add the integration.
5. Copy the page link (`•••` > **Copy link**).

## 2. GitHub setup

In the repo, open **Settings > Secrets and variables > Actions** and add:

- a **secret** named `NOTION_TOKEN` with the integration token.
- a **variable** named `NOTION_LIBRARY_PAGE` with the Diagrams page link. It isn't
  sensitive.

Or from a terminal (the secret prompt hides what you type):

```bash
gh secret set NOTION_TOKEN
gh variable set NOTION_LIBRARY_PAGE --body "https://www.notion.so/Diagrams-..."
```

### `scripts/export.mjs`

Renders every `.excalidraw` file in the repo to `build/<same path>.png` at 2x scale.

```js
import { chromium } from "playwright";
import { mkdirSync, readdirSync, readFileSync, writeFileSync } from "node:fs";
import { dirname, join } from "node:path";

const OUT_DIR = "build";
const SCALE = 2;
const PADDING = 20;
const UTILS_VERSION = "0.1.5";
const SKIP_DIRS = new Set([".git", "node_modules", OUT_DIR]);

function findDiagrams(dir = ".") {
  const found = [];
  for (const entry of readdirSync(dir, { withFileTypes: true })) {
    if (SKIP_DIRS.has(entry.name)) continue;
    const path = join(dir, entry.name);
    if (entry.isDirectory()) found.push(...findDiagrams(path));
    else if (entry.name.endsWith(".excalidraw")) found.push(path);
  }
  return found;
}

// Loads the official Excalidraw export code into the page.
// EXCALIDRAW_ASSET_PATH tells it where to fetch fonts from.
const PAGE = `<!doctype html><html><body><script type="module">
  window.EXCALIDRAW_ASSET_PATH = "https://unpkg.com/@excalidraw/utils@${UTILS_VERSION}/dist/prod/";
  import * as ExcalidrawUtils from "https://esm.sh/@excalidraw/utils@${UTILS_VERSION}";
  window.ExcalidrawUtils = ExcalidrawUtils;
  window.ready = true;
</script></body></html>`;

const diagrams = findDiagrams();
if (diagrams.length === 0) {
  console.log("No .excalidraw files found.");
  process.exit(0);
}

const browser = await chromium.launch();
const page = await browser.newPage();
page.on("pageerror", (err) => console.error("[page error]", err.message));
await page.setContent(PAGE);
await page.waitForFunction(() => window.ready === true, null, { timeout: 60_000 });

let failed = false;
for (const input of diagrams) {
  const output = join(OUT_DIR, input.replace(/\.excalidraw$/, ".png"));
  try {
    const scene = JSON.parse(readFileSync(input, "utf8"));
    const base64 = await page.evaluate(
      async ({ scene, scale, padding }) => {
        const blob = await window.ExcalidrawUtils.exportToBlob({
          data: {
            elements: scene.elements,
            appState: { ...scene.appState, exportBackground: true },
            files: scene.files ?? {},
          },
          config: { mimeType: "image/png", scale, padding },
        });
        return await new Promise((resolve, reject) => {
          const reader = new FileReader();
          reader.onload = () => resolve(reader.result.split(",")[1]);
          reader.onerror = () => reject(reader.error);
          reader.readAsDataURL(blob);
        });
      },
      { scene, scale: SCALE, padding: PADDING },
    );
    mkdirSync(dirname(output), { recursive: true });
    writeFileSync(output, Buffer.from(base64, "base64"));
    console.log(`Rendered ${input} -> ${output}`);
  } catch (err) {
    failed = true;
    console.error(`Failed to render ${input}: ${err.message}`);
  }
}

await browser.close();
process.exit(failed ? 1 : 0);
```

### `scripts/upload-to-notion.mjs`

Uploads every rendered PNG and syncs the library page. It keeps going after an error
and fails the run at the end, so one broken diagram doesn't stop the others.
`NOTION_API_URL` is only an override for testing against a fake API.

```js
import { readdirSync, readFileSync } from "node:fs";
import { basename, join, relative, sep } from "node:path";

const API = process.env.NOTION_API_URL ?? "https://api.notion.com/v1";
const NOTION_VERSION = "2026-03-11";
const OUT_DIR = "build";
const TOKEN = process.env.NOTION_TOKEN;
const LIBRARY = process.env.NOTION_LIBRARY_PAGE;

if (!TOKEN || !LIBRARY) {
  console.error("NOTION_TOKEN and NOTION_LIBRARY_PAGE must both be set.");
  process.exit(1);
}

async function notion(path, { method = "GET", json, form } = {}) {
  for (let attempt = 1; ; attempt++) {
    const res = await fetch(`${API}${path}`, {
      method,
      headers: {
        Authorization: `Bearer ${TOKEN}`,
        "Notion-Version": NOTION_VERSION,
        ...(json ? { "Content-Type": "application/json" } : {}),
      },
      body: json ? JSON.stringify(json) : form,
    });
    // Back off and retry when Notion rate-limits us.
    if (res.status === 429 && attempt < 5) {
      const seconds = Number(res.headers.get("retry-after") ?? attempt);
      await new Promise((r) => setTimeout(r, seconds * 1000));
      continue;
    }
    const body = await res.json().catch(() => ({}));
    if (!res.ok) {
      throw new Error(`${method} ${path} returned ${res.status} ${body.code ?? ""}: ${body.message ?? ""}`);
    }
    return body;
  }
}

// Accepts a page URL or a bare ID, with or without dashes.
function toPageId(ref) {
  const raw = ref.split(/[?#]/)[0].replace(/-/g, "").slice(-32);
  if (!/^[0-9a-f]{32}$/i.test(raw)) throw new Error(`Not a valid page ID or page link: ${ref}`);
  return raw;
}

async function listChildren(blockId) {
  const children = [];
  let cursor;
  do {
    const query = `page_size=100${cursor ? `&start_cursor=${cursor}` : ""}`;
    const page = await notion(`/blocks/${blockId}/children?${query}`);
    children.push(...page.results);
    cursor = page.has_more ? page.next_cursor : undefined;
  } while (cursor);
  return children;
}

function plainText(block) {
  return (block[block.type]?.rich_text ?? []).map((t) => t.plain_text ?? t.text?.content ?? "").join("").trim();
}

// The library page holds, per diagram, a heading with the diagram's repo path followed
// by a synced block that contains the image. Copies of the synced block elsewhere in
// Notion show only the image and follow every update.
async function readLibrary(pageId) {
  const entries = new Map();
  const blocks = await listChildren(pageId);
  for (let i = 0; i < blocks.length - 1; i++) {
    const heading = blocks[i];
    const synced = blocks[i + 1];
    if (heading.type !== "heading_3" || synced.type !== "synced_block") continue;
    if (synced.synced_block.synced_from !== null) continue;
    const image = (await listChildren(synced.id)).find((b) => b.type === "image");
    if (image) entries.set(plainText(heading), image.id);
  }
  return entries;
}

function findPngs(dir = OUT_DIR) {
  const found = [];
  for (const entry of readdirSync(dir, { withFileTypes: true })) {
    const path = join(dir, entry.name);
    if (entry.isDirectory()) found.push(...findPngs(path));
    else if (entry.name.endsWith(".png")) found.push(path);
  }
  return found;
}

async function uploadPng(pngPath) {
  const filename = basename(pngPath);
  const created = await notion("/file_uploads", {
    method: "POST",
    json: { filename, content_type: "image/png" },
  });
  const form = new FormData();
  form.append("file", new Blob([readFileSync(pngPath)], { type: "image/png" }), filename);
  const sent = await notion(`/file_uploads/${created.id}/send`, { method: "POST", form });
  if (sent.status !== "uploaded") throw new Error(`Upload of ${filename} ended with status ${sent.status}`);
  return created.id;
}

async function updateImage(blockId, uploadId) {
  await notion(`/blocks/${blockId}`, {
    method: "PATCH",
    json: { image: { file_upload: { id: uploadId } } },
  });
}

async function addToLibrary(pageId, diagram, uploadId) {
  await notion(`/blocks/${pageId}/children`, {
    method: "PATCH",
    json: {
      children: [
        { type: "heading_3", heading_3: { rich_text: [{ type: "text", text: { content: diagram } }] } },
        {
          type: "synced_block",
          synced_block: {
            synced_from: null,
            children: [{ type: "image", image: { type: "file_upload", file_upload: { id: uploadId } } }],
          },
        },
      ],
    },
  });
}

const pageId = toPageId(LIBRARY);
const library = await readLibrary(pageId);
const errors = [];

for (const png of findPngs().sort()) {
  const diagram = relative(OUT_DIR, png).split(sep).join("/").replace(/\.png$/, ".excalidraw");
  const imageId = library.get(diagram);
  library.delete(diagram);
  try {
    const uploadId = await uploadPng(png);
    if (imageId) {
      await updateImage(imageId, uploadId);
      console.log(`Updated ${diagram}`);
    } else {
      await addToLibrary(pageId, diagram, uploadId);
      console.log(`Added ${diagram} to the library page`);
    }
  } catch (err) {
    errors.push(`${diagram}: ${err.message}`);
  }
}

for (const orphan of library.keys()) {
  console.warn(`Note: ${orphan} is on the library page but no longer in the repo. Remove it by hand if it's gone for good.`);
}

if (errors.length > 0) {
  console.error(`\n${errors.length} problem(s):`);
  for (const e of errors) console.error(`- ${e}`);
  process.exit(1);
}
console.log("The Notion library page is up to date.");
```

### `.github/workflows/publish-diagrams.yml`

```yaml
name: Publish diagrams to Notion

on:
  push:
    branches: [main]
    paths:
      - "**.excalidraw"
      - "scripts/**"
      - "package.json"
      - "package-lock.json"
      - ".github/workflows/publish-diagrams.yml"
  workflow_dispatch:

# Only the newest run matters, because every run uploads every diagram.
concurrency:
  group: publish-diagrams
  cancel-in-progress: true

permissions:
  contents: read

jobs:
  publish:
    runs-on: ubuntu-latest
    timeout-minutes: 15
    steps:
      - uses: actions/checkout@v5

      - uses: actions/setup-node@v5
        with:
          node-version: 24
          cache: npm

      - run: npm ci

      - name: Install headless Chromium
        run: npx playwright install --with-deps --only-shell chromium

      - name: Render diagrams
        run: npm run export

      - name: Keep rendered PNGs as a build artifact
        uses: actions/upload-artifact@v4
        with:
          name: diagrams
          path: build/

      - name: Update Notion
        run: npm run publish:notion
        env:
          NOTION_TOKEN: ${{ secrets.NOTION_TOKEN }}
          NOTION_LIBRARY_PAGE: ${{ vars.NOTION_LIBRARY_PAGE }}
```

## 5. Testing it

1. **Render locally first.**

   ```bash
   npm install
   npx playwright install chromium
   npm run export
   open build/test3.png
   ```

2. **Sync locally once.** This checks the token and the page connection without
   involving CI. Put the token in a `.env` file, which git ignores:

   ```bash
   NOTION_LIBRARY_PAGE="https://www.notion.so/Diagrams-..." \
     node --env-file=.env scripts/upload-to-notion.mjs
   ```

   The Diagrams page should now list every diagram. Run it again and the output should
   say "Updated" instead of "Added".

3. **Place a diagram on another page.** On the library page, click the synced block's
   border (not the image), choose **Copy and sync**, and paste it into another page.
   Pages that show a copy don't need the integration connection.

4. **Test CI.** Push to `main`, or run the workflow by hand from the **Actions** tab.
   Then change a diagram, push again, and reload both pages.

## 6. Day-to-day use

**Adding a diagram:** add the `.excalidraw` file to the repo and merge to `main`. It
appears at the bottom of the library page after the run.

**Using a diagram on a page:** copy its synced block from the library page and paste
it.

**Updating a diagram:** edit the `.excalidraw` file and merge to `main`. Every copy
updates within about a minute of the run finishing.

**Removing a diagram:** delete the file from the repo, then delete its heading and
synced block from the library page by hand. Copies elsewhere then turn into normal
blocks that no longer update.

**Don't rename, reorder or separate** a heading and its synced block on the library
page. The script finds each diagram by its heading text followed directly by its
synced block. Renaming a file in the repo creates a new library entry, so existing
copies keep showing the old one until you swap them.

## 7. Troubleshooting

| Error in the run log | Likely cause |
| --- | --- |
| `NOTION_TOKEN and NOTION_LIBRARY_PAGE must both be set` | The repo secret or the repo variable is missing or misspelled. |
| `Not a valid page ID or page link` | The `NOTION_LIBRARY_PAGE` value isn't a Notion page link. |
| `401 unauthorized` | The token is wrong, revoked, or expired. |
| `404 object_not_found` | The library page isn't connected to the integration. |
| `403 restricted_resource` | The integration is missing a capability, most likely Insert content. |
| A diagram is added a second time | Its heading was edited or moved away from its synced block. Delete the duplicate and fix the original. |
| Chromium fails to launch | The Playwright install step failed. Check its log. |

## 8. Assumptions and known limits

- **The renderer downloads Excalidraw from public CDNs.** The page loads
  `@excalidraw/utils` from esm.sh and its fonts from unpkg, pinned to version 0.1.5. If
  a CDN is down, the render step fails and Notion keeps the previous images.
- **Every run re-uploads every diagram.** This keeps the logic simple. It's fine for a
  few dozen diagrams.
- **Old uploads stay in Notion's storage.** Replacing an image doesn't delete the
  previous file. Free workspaces limit each file to 5 MiB, which diagram PNGs stay well
  under.
- **Exports use a white background and light mode.** The background follows the
  diagram's own background color setting.
- **Captions are untouched.** A caption on the image inside a synced block shows on
  every copy.
- **The `2026-03-11` Notion API version** comes from Notion's current upload guide.
  If Notion rejects it, use the version shown in their API reference.
